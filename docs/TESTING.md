# TaskFlow テスト仕様書

## 1. テスト環境

| 項目 | 内容 |
|---|---|
| バックエンド | Laravel 12 |
| テストフレームワーク | PHPUnit |
| データベース | SQLite（インメモリ） |
| 実行環境 | Docker Compose |

## 2. テスト実行方法

以下のコマンドで全テストを実行する。

```bash
docker compose exec app php artisan test
```
## 3. テスト対象

### タスク機能
- タスクの新規作成
- タスク一覧の取得
- タスクの更新
- タスクの論理削除
- 不正な入力値のバリデーション
- 他ワークスペースのタスクへの更新・削除拒否
- 他ワークスペースのカテゴリを指定できないこと

### カテゴリ機能
- カテゴリの新規作成
- カテゴリ一覧の取得
- カテゴリの更新
- カテゴリの削除
- 不正な入力値のバリデーション
- 同一ワークスペース内のカテゴリ名重複防止
- 他ワークスペースのカテゴリへのアクセス拒否

### 認証・アクセス制御
- 未認証ユーザーによるタスクAPIへのアクセス拒否
- 未認証ユーザーによるカテゴリAPIへのアクセス拒否
